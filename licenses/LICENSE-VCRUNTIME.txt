Microsoft Visual C++ Redistributable (vcruntime140.dll)
=======================================================

vcruntime140.dll (14.29.30037.0) is a Microsoft Visual C++ Redistributable
runtime component. It is bundled with MrOpenVPN Client for Windows because
openvpn.exe (from the official OpenVPN for Windows build) links against the
MSVC C runtime.
